# 🎧 TechWave — Ultra-Premium SaaS Podcast Platform

![TechWave Banner](https://images.unsplash.com/photo-1519389950473-47ba0277781c?w=1200&q=80)

**TechWave** is a modern, ultra-premium, and fully responsive podcast website built with a "SaaS-level" design philosophy. It features glassmorphism, dynamic particle animations, dark/light theme modes, embedded YouTube video episodes, and 20+ detailed sections — all in pure HTML, CSS, and JavaScript.

---

## ✨ Key Features

- 🎨 **Ultra-Modern SaaS Design** — Glassmorphism, animated gradient orbs, floating particles, and glowing effects.
- 🌙 **Dark/Light Theme Toggle** — Persistent via `localStorage`, with smooth transitions.
- 🎬 **Working YouTube Video Episodes** — 3 fully embedded, playable videos in the "Featured Episodes" section.
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop (breakpoints at 1200px, 992px, 576px).
- 🧩 **20+ Detailed Sections** — Hero, Marquee, About, Why Choose, Episodes, Host, Experts, Categories, How It Works, Trust, Impact, Testimonials, Articles, Pricing, Admin, Contact, CTA, Footer, and more.
- 🎯 **Micro-Interactions** — Ripple effects on buttons, scroll-reveal animations, animated counters, and hover lift effects.
- 🚀 **Performance Optimized** — Preloader, lazy rendering, and canvas particle animations that pause when out of view.
- 🎨 **Custom Scrollbar** — Gradient purple/pink styling for a polished feel.
- 📦 **No Dependencies** — Built with pure HTML5, CSS3, and vanilla JavaScript.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **HTML5** | Semantic structure, embedded YouTube iframes |
| **CSS3** | Custom properties, grid/flexbox, glassmorphism, animations, responsive design |
| **JavaScript (Vanilla)** | Theme toggle, particle canvas, scroll observers, ripple effects, form handling |
| **Font Awesome 6.5.2** | Iconography across all sections |
| **Google Fonts** | Inter (body), Space Grotesk (headings), DM Mono (labels/tags) |
